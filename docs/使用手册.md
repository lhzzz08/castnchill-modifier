# Cast n Chill 修改器 · 使用手册

> 面向日常使用的操作手册。功能总览与技术细节见 `README.md`，设计文档见 `DESIGN.md`。

---

## 一、三分钟上手（每天的打开方式）

1. **开 Steam**（保持登录状态）
2. **启动游戏**：双击 `~/.castnchill-modifier/cnc`（或仓库 `launcher/cnc`）
   - 它会自动：校验游戏版本 → 备份存档 → 注入修改器 → 拉起游戏
   - 看到 `[cnc] 注入启动：...` 即成功
3. **开面板**：应用程序里的 CNCPanel
4. 面板顶部出现 **绿点「已连接游戏」** → 一切就绪

> ⚠️ 必须经 `cnc` 启动游戏。从 Steam 直接点"开始游戏"的话游戏里没有修改器，面板会是红点。

## 二、面板操作速查

### 💰 金钱区
| 想做什么 | 怎么做 |
|---|---|
| 快速加钱 | 点 `+1万` / `+10万` |
| 精确设钱 | 金额框输入数字 → 点 `设定` |
| 买东西不花钱 | 打开 `消费不减`（买了自动退钱，赚钱不受影响） |
| 卖鱼赚翻倍 | 拖 `售价` 滑杆（如 10×）→ 点 `一键卖出` |

### 🐟 卖鱼区
- **一键卖出**：把船存里待售的鱼全部卖掉变现（卖完船存自然腾空）

### 🎣 钓鱼增强（每个开关：改了什么 · 场景 · 开启后的体感）

| 开关 | 改了什么 | 推荐场景 | 开启后的体感 |
|---|---|---|---|
| 秒赢对决 | 鱼战斗时长直接归 0.05 秒（不再依赖体力倍率） | 嫌拉鱼漫长；挂机刷图鉴 | 咬钩后几乎立刻拉上来，全程 1-2 秒 |
| 即时上钩 | 咬钩率 100% + 吸引力拉满 + 鱼追饵意愿 60 秒 | 放置挂机、快速刷鱼 | 抛竿后鱼群围上来反复咬钩，第一口就中 |
| 不断之线 | 断线计时 86400 秒（满张力挂一天才会断） | 硬拉大鱼 | 张力/震动反馈照常，实际不可能断 |
| 无限体力 | 划船/走路/破冰消耗=0（**仅玩家体力条**，钓鱼对决用秒赢对决） | 开船长途跑图、冰面 | 开船时体力条不减 |
| 超级投掷 | 甩竿动作 ×1.5 + 飞行阻力降低 + 飞行速度上限 ×3 | 够远处鱼群 | 落点比平时远一截；蓄力条摆动稍快，掐时机要适应 |

**架构说明（v3）**：所有开关改为**常驻重应用**——每 2 秒重新枚举游戏资产并重写补丁值，对抗游戏延迟加载资产导致的失效；关闭开关立即恢复原值并停止轮询。

**组合推荐**：放置挂机 = 即时上钩 + 秒赢对决 + 不断之线 + 加速 4×；手动爽钓 = 即时上钩 + 收线 3× + 不断之线。
**验证技巧**：开关开启时 mod 日志会打印改写实例数（`cat /tmp/cnc-mod.log`，如 `秒赢对决 → FishData.stamina=1 (68 实例)`）；关掉开关全部恢复原值。

### ⚡ 速度区
- **加速滑杆**：游戏整体加速 0.5–16×（挂机神技，配合放置模式）
- **船速 ×N**：船引擎极速/加速度/放置闲逛船速/码头走路整体提速

## 三、存档编辑器（离线工具，先退游戏）

存档位置：`~/Library/Application Support/Wombat Brawler/Cast n Chill/Journals/journal0001`
编辑器：`~/.castnchill-modifier/cnc_save.py`（每次写入前自动备份）

```bash
# 看看存档现状（现金/图鉴/外观统计）
cnc_save.py show <存档>

# 改钱
cnc_save.py cash <存档> set 100000

# 全解锁：全鱼图鉴 + 全外观（皮肤/服装/帽/饵/竿 ×双钓手）
cnc_save.py unlock <存档> all

# 直接"钓到"指定鱼（下次进游戏自动卖出变现 + 图鉴点亮）
cnc_save.py catch <存档> arctic-char 150
# 鱼名清单在 ~/.castnchill-modifier/game-ids.json（68 种）

# 出事了回滚
cnc_save.py restore <存档> <备份文件名>
```

**典型场景**：
- *"我想要全图鉴"* → 退游戏 → `unlock <存档> fish` → 开游戏
- *"给我来十条传说鱼"* → 退游戏 → 连跑十次 `catch <存档> <鱼名>` → 开游戏收钱
- *"改坏了"* → `ls` 看备份 → `restore` 回滚（启动器每次启动还会自动备份到 `~/.castnchill-modifier/backups/`）

## 四、命令行直控（进阶）

面板只是壳，底层是 Unix socket，任何终端都能发命令：

```bash
S=/tmp/cnc-mod-$(id -u).sock
printf 'cash.add 50000\n' | nc -U $S     # 加钱
printf 'fish.bite on\n'     | nc -U $S   # 开即时上钩
printf 'state.get\n'        | nc -U $S   # 总状态
```

全部命令清单见 `README.md` 功能表（`sell.mult`/`reel.fast`/`time.set`/`storage.max` 等进阶命令不在面板露出，可用命令行直控）。可以自己写脚本做自动化（比如每 10 分钟自动卖鱼）。

## 五、出了问题怎么办

| 症状 | 原因与解法 |
|---|---|
| 游戏崩溃后重启，卡在启动画面不动 | macOS"恢复窗口"对话框死锁。启动器已自动规避；仍卡就删 `~/Library/Logs/DiagnosticReports/Cast*` 再开 |
| 游戏点开秒退，无任何弹窗 | Steam 崩溃计数脏了。**重启 Steam 客户端**即可 |
| 面板红点不连 | 游戏不是经 `cnc` 启动的；或游戏已退出 |
| 改的钱重启后没了 | 不会发生（原生 CashTip 落盘）。若遇到说明走错通道了，截图 `/tmp/cnc-mod.log` 反馈 |
| 面板提示版本不匹配 | 游戏更新了。按名解析大概率仍可用；个别功能失效等适配即可，不会崩游戏 |
| 想看 mod 日志 | `cat /tmp/cnc-mod.log` |

## 六、注意事项

1. **Steam 云同步**：改档前先退游戏（编辑器会提醒），避免本地/云端冲突
2. **成就**：作弊可能触发成就解锁（本修改器不提供拦截，已按需求移除）——介意的话开 `消费不减` 类功能前想清楚
3. **数值上限**（防玩坏）：加速 ≤16×、倍率 ≤100×、单次金钱 ≤10 亿
4. **游戏本体零污染**：所有改动只在内存与存档文件里，Steam「验证文件完整性」永远是干净的

```bash
rm -rf ~/.castnchill-modifier     # 组件 + 备份全清
# CNCPanel 拖进废纸篓即可；游戏无需任何处理
```
